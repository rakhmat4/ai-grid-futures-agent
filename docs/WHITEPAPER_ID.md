# White Paper Ringkas — AI Grid Futures Agent

## Latar Belakang

Grid futures bisa menghasilkan win rate tinggi, tetapi rentan terhadap trend satu arah, fee drag, funding drag, slippage, liquidation risk, dan overfitting.

## Tujuan

Membangun research engine yang mampu:

1. Mengambil data pasar futures.
2. Melakukan backtest grid futures.
3. Mengoptimasi parameter dengan Optuna.
4. Membandingkan pair altcoins.
5. Menolak strategi berisiko tinggi.
6. Memberi rekomendasi paper-test candidate.

## Modul

- Data Agent
- Backtest Agent
- Optuna Optimization Agent
- Risk Intelligence Agent
- Report Agent

## Pair Awal

- ADAUSDT
- XRPUSDT
- TRXUSDT

## Hasil Awal

TRXUSDT paling stabil tetapi profit masih kecil. ADAUSDT dan XRPUSDT stopped out. Belum ada strategi yang layak live market.

## Rekomendasi

Lanjutkan ke V3:

- ATR-based grid range
- Trend filter
- Walk-forward validation
- Funding fee simulation
- Paper trading mode
